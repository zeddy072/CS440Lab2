# Code Refactor Skill

## Instructions
1. Inspect the target file using `read_file`.
2. Analyze code complexity, variable naming, and function length.
3. Propose or apply minimal, safe transformations using `patch_file` or `write_file`.
4. Ensure existing unit tests continue to pass after any changes.
